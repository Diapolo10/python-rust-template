# project-name

Remember to:

1. Replace all instances of `project-name` with the real name of the project
2. Rename the source code folder from `project_name` to something more fitting
3. Generate a lock file
4. Rewrite the `README.md`

## Tasks

- `task install`: Install dependencies.
- `task lint`: Run code linting.
- `task test`: Run tests.
- `task build`: Build the project.
- `task format`: Format codebase.
- `task clean`: Clean temporary files.

## Version Management

Mise ensures consistent runtimes across development and CI by using a lockfile (`mise.toml`).
No manual version management is required.
